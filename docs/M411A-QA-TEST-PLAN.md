# 麦动 KTV 多人点歌与 M411A 实机验收计划

> 本文用于区分自动化可验证项目与必须在真实设备上完成的验收项目。未取得实测记录前，不得标记为通过。

## 1. 多人点歌（局域网）

### 测试环境
- 至少 2 台手机/客户端连接同一局域网。
- KTV 主机与客户端处于同一网段；记录主机 IP、客户端数量、应用版本。
- 测试前清空或记录点歌队列，避免旧数据干扰。

### 用例
| 编号 | 场景 | 操作 | 通过标准 |
|---|---|---|---|
| LAN-01 | 双人同时点歌 | 两台客户端在 1 秒内提交不同歌曲 | 两首均被接收，队列顺序明确，无崩溃 |
| LAN-02 | 多人同时点同一首 | 至少 2 台客户端同时提交同一歌曲 | 按产品既定规则处理；不出现意外重复或丢失 |
| LAN-03 | 连续重复点歌 | 同一客户端快速重复提交同一歌曲 | 去重/允许重复行为符合产品规则，队列状态一致 |
| LAN-04 | 断网重连 | 客户端断开 Wi-Fi 后重新连接 | 恢复轮询后能获取最新队列，不重复提交历史请求 |
| LAN-05 | 主机短暂离线 | 点歌主机重启或短暂断网 | 客户端能恢复连接，界面不永久卡死 |
| LAN-06 | 队列并发更新 | 一台添加歌曲，另一台删除/切歌（如支持） | 最终状态一致，无旧状态覆盖新状态 |
| LAN-07 | 长时间轮询 | 连续运行至少 2 小时 | 无明显内存增长、卡死或队列漂移 |

### 手机端歌手分类与搜索
| 编号 | 场景 | 操作 | 通过标准 |
|---|---|---|---|
| MOB-01 | 分类入口 | 手机扫码后切换到“歌手”模式 | 显示全部、内地、港台、男歌手、女歌手、组合分类 |
| MOB-02 | 分类数据 | 分别打开六种分类并翻页 | 列表来自曲库歌手区域/类型字段，分类结果正确 |
| MOB-03 | 歌手歌曲 | 选择一位歌手 | 显示该歌手歌曲，可正常点歌 |
| MOB-04 | 搜索兼容 | 输入歌手名/拼音搜索 | 结果正确，分页不混入歌手列表 |

### 记录
每个用例记录：日期、应用版本、主机/客户端型号、网络条件、操作时间、预期结果、实际结果、日志/截图、通过/失败/阻塞。

## 2. M411A 实机验收

必须使用实际 M411A 设备完成。模拟器、源码检查和 CI 构建不能替代实机通过结论。

| 编号 | 场景 | 操作 | 通过标准 |
|---|---|---|---|
| M411A-01 | 安装 | 安装本次 QA APK；记录原系统与安装方式 | 安装成功，无签名/ABI/SDK 错误 |
| M411A-02 | 冷启动 | 强制停止后重新启动，重复 5 次 | 每次正常进入，无闪退 |
| M411A-03 | 播放 | 播放本地/网络测试曲目（注明来源） | 音视频正常，无持续卡顿或无声 |
| M411A-04 | 遥控器 | 方向、确认、返回、音量等按键 | 焦点移动正确，关键操作可完成 |
| M411A-05 | 扫码点歌 | 手机扫码、连接、提交歌曲 | 配对和点歌成功，队列及时同步 |
| M411A-06 | 麦克风/音频 | 按实际接线测试麦克风、音响/声卡 | 输入输出符合设备接线预期，无异常崩溃 |
| M411A-07 | 断网恢复 | 播放或点歌过程中断网再恢复 | 应用可恢复，状态符合产品预期 |
| M411A-08 | 长稳运行 | 连续运行至少 8 小时，期间播放和操作 | 无闪退、死锁、明显音频中断或不可恢复故障 |

## 3. 自动化 CI 验收

- 运行现有单元测试任务。
- 成功构建 Debug QA APK。
- 保存构建日志与 APK Artifact。
- CI 通过仅表示自动化测试和构建通过，不表示多人局域网或 M411A 实机验收通过。

## 4. 交付状态规则

每项只允许标记为：
- **通过**：有可复核的实际测试记录。
- **失败**：已复现并记录问题。
- **阻塞**：缺少设备、网络、外部服务或测试条件。
- **未测试**：尚未执行。

最终交付需包含 APK、安装步骤、构建提交号、CI 结果、测试矩阵及遗留问题。任何没有实机记录的 M411A 项目必须保留为“未测试”或“阻塞”。
